# Prompts

1. Explain how a task management dashboard can be structured to display tasks, priorities, projects, and productivity information clearly.

2. Explain how Next.js App Router organizes routes using folders and `page.js` files.

3. Explain how authentication pages such as login, registration, and forgot-password should work in a web application.

4. Explain the difference between public routes and protected workspace routes in a task management application.

5. Explain how task status and priority can be represented in a task management interface.

6. Explain common approaches for organizing tasks by projects and displaying project progress.

7. Explain how a calendar view can be used to display task deadlines and scheduled activities.

8. Explain how drag-and-drop task organization works and how it can improve task management.

9. Explain how task search and filtering can be implemented using task title, status, priority, and project information.

10. Explain how task creation and editing forms should handle fields such as title, description, priority, status, project, and due date.

11. Explain how Redux Toolkit can be used to manage shared task and application state.

12. Explain how reusable React components can be used for task cards, task forms, modals, drawers, navigation, and other repeated interface elements.

13. Explain how loading, empty, success, and error states should be handled in a task management application.

14. Explain how a Next.js API route can communicate with an external AI service without exposing the API key to the client.

15. Explain how an AI service such as Groq can generate useful subtasks from a task title and description.

16. Explain how AI-generated subtasks can be presented to users and incorporated into an existing task workflow.

17. Explain how user profile, settings, and team member sections can be organized within a workspace application.

18. Explain responsive design considerations for a dashboard containing side navigation, task sections, modals, forms, and calendar views.

19. Explain common code organization practices for a Next.js application containing authentication, workspace pages, API routes, Redux state, utilities, and styling.

20. Review the general architecture of an AI-powered task management application and explain the important areas to check for usability, maintainability, security, and production readiness.
